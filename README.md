# 杖剑传说「糖果消消夜」辅助脚本

基于 `pyautogui`、Quartz 和 OpenCV 的 macOS 三消辅助脚本。识别 7 列 × 9 行棋盘，计算合法交换并自动滑动，支持消除特效期间使用其他清晰区域继续操作。

## 工作原理

1. 通过 Quartz 按窗口 ID 截取游戏画面，避免截到前方的其他应用，并处理 Retina 坐标换算。
2. 普通棋子使用中央 80×80 区域，绿色鬼脸使用中央 64×64 面部区域进行模板匹配，减少背景和外圈动态光效干扰。
3. 强光、浮字或移动中的格子标为未知，不猜测类别；每格独立确认连续帧，初始化后不再等待整盘静止。
4. 检测到绿色鬼脸且相邻格清晰可见时，优先执行一次相邻交换，不要求形成三连，日志显示 `[SPECIAL]`。
5. 枚举普通棋子的所有向右、向下相邻交换，只保留能形成新三连及以上的操作。
6. 模拟消除和已知棋子下落，按确定总消除数、立即消除数、最长匹配和较低位置选择候选。
7. 使用 `pyautogui.dragTo` 滑动；遮挡区域没有可靠操作时，只搜索其他清晰格子，没有合法候选则等待下一帧。

随机补充的棋子不参与“确定收益”预测，因此脚本不会承诺理论最优或固定分数。

## 安装

需要 macOS、Python 3.14 和 [uv](https://github.com/astral-sh/uv)：

```bash
uv sync
```

在 macOS「系统设置 → 隐私与安全性」中，给运行脚本的终端或 VS Code 开启：

- **屏幕录制**：用于读取游戏画面；
- **辅助功能**：用于全局 ESC 监听以及鼠标点击、拖拽。

权限变更后需要重新启动终端或 IDE。

## 使用

保持「杖剑传说」窗口可见，进入糖果消消夜开始页；已经处于棋盘中也可以直接接管。

```bash
uv run main.py
```

- 在开始页运行时，脚本自动点击一次开始按钮，等待 321 倒计时和棋盘稳定。
- 如果自动点击未被游戏接受，可以手动点击开始，脚本会继续识别，不会反复点击开始按钮。
- 脚本自动进行交换，检测到「挑战成功」后停止，不自动退出或开下一局。
- 按 **ESC** 可随时停止，也支持 Ctrl+C 和将鼠标移到屏幕左上角触发 PyAutoGUI 急停。

## 安全识别与调试

只识别真实窗口并给出建议，不点击或滑动：

```bash
uv run main.py --dry-run
```

离线识别提供的静态截图：

```bash
uv run main.py --image "images/游戏中画面.png"
```

输出每轮耗时并保存 `debug/current.png`：

```bash
uv run main.py --debug
```

诊断图中，红框表示尚未稳定或被遮挡的格子，绿色箭头表示当前建议交换。`debug/` 已被 Git 忽略。

## 节奏参数

默认值偏保守，避免游戏还未接受上一个手势就继续操作。可直接在命令行调整，不需要修改源码。

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `--detect-interval-ms` | 100 | 每轮检测的最小间隔 |
| `--cell-stable-frames` | 2 | 每格被视为稳定所需的连续识别帧数 |
| `--swipe-duration-ms` | 120 | 一次拖拽的持续时间 |
| `--post-swipe-delay-ms` | 120 | 滑动后重新开始检测前的等待 |
| `--min-swipe-interval-ms` | 300 | 两次滑动的最小间隔 |
| `--threshold` | 0.72 | 棋子模板匹配的最低置信度 |

如果漏滑、分数不变或游戏反应不过来，先增大等待，例如：

```bash
uv run main.py --post-swipe-delay-ms 200 --min-swipe-interval-ms 450 --swipe-duration-ms 160
```

如果清晰棋子经常在未知与正常之间跳动，可以增加稳定帧或检测间隔：

```bash
uv run main.py --cell-stable-frames 3 --detect-interval-ms 120
```

如果实际运行稳定并希望提速，再逐步减小 `--min-swipe-interval-ms` 或 `--post-swipe-delay-ms`，每次只调整一项并观察得分和漏滑情况。识别提速本身不会自动缩短手势安全间隔。

## 文件说明

- `main.py`：窗口截图、棋子识别、交换求解、状态控制和命令行入口；
- `images/templates/`：5 种普通棋子、绿色鬼脸及开始、结算状态模板；
- `images/`：开始、游戏中、结束和绿色特殊卡牌参考截图；
- `videos/消除特效_压缩.mp4`：消除白光、分数浮字和连击浮层的验证录屏。

本项目仅用于个人学习和娱乐，请遵守游戏服务条款。
